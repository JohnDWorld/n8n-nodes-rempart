# n8n-nodes-rempart

n8n community nodes for [Rempart Messenger](https://rempart-messenger.fr), an end-to-end encrypted messenger hosted in France.

> **Work in progress.** The nodes are being written and are not published on npm yet.

Planned:

- **Rempart Trigger**: starts a workflow when your Rempart bot receives a message or a reaction.
- **Rempart**: send messages (with buttons), photos and documents, edit or delete them, show "typing", download received files, and **Send and Wait for Response** to pause a workflow until someone answers.

The nodes talk to the [Rempart bot gateway](https://rempart-messenger.fr/api-bots.md) with the token of a bot created in Rempart > My bots.
